# Wanaka 引擎 · Floor is Lava 创作 Prompt

场景锁定：**玩家在一栋大楼里往上爬楼梯**，熔岩从一楼往上追。  
不要院子、别墅、泳池、开放岛屿。整张图就是楼内楼梯间 + 每层休息平台。

把下面的 **短 Prompt** 贴进 [Wanaka Studio](https://studio.wanaka.fun/) 的 Create 输入框。  
生成后把 **完整 Prompt** 发给创作代理，再按 **迭代 Prompt** 一条条打磨。

---

## 1. 短 Prompt（先贴这一段）

```
做一个第三人称 3D「地板即熔岩」游戏：整张图只发生在一栋室内大楼的楼梯间。玩家从一楼大堂出生，核心玩法就是沿楼梯往上爬，逃离从楼下涌上来的熔岩。1–8 人，浏览器可玩。

大楼 6 层，每层有休息平台和一段折返楼梯。开局 5 秒倒计时后，一楼地面变成发光熔岩（触发即死，不可站立），熔岩沿楼梯井持续上涨。玩家用角色控制器跑跳（含二段跳、土狼时间），踩楼梯踏步、休息平台、断裂台阶边缘和少量可推纸箱往上逃。部分踏步站 1.2 秒后开裂掉落；有的梯段缺了几级，必须跳过去。先到楼顶天台安全门的人获胜；多人则看谁爬得最高、谁最后被熔岩追上。

画面：风格化室内，应急灯冷光，楼梯井下方熔岩自发光把墙映红，热浪雾从井底往上涌。操作：WASD 移动，空格跳跃，鼠标转视角。不要室外场景、电梯通关、商店或剧情。先让从 1 楼爬到 6 楼这一条楼梯好玩。
```

English (if the agent responds better in English):

```
Build a third-person 3D Floor-is-Lava game set entirely inside one building stairwell. Players spawn in the lobby and climb the stairs to escape lava rising from below. 1–8 players, playable in the browser on the Wanaka engine.

The map is a 6-story indoor stairwell with landings and switchback flights. After a 5-second countdown, the ground floor becomes emissive lava: a kill trigger, not a walkable collider. Lava keeps rising up the stair shaft. Use a character controller (run, jump, double jump, coyote time). Safe surfaces: steps, landings, broken-step edges, a few pushable cardboard boxes. Some steps crack after 1.2s of standing; some flights are missing steps and must be jumped. First to the rooftop fire door wins; in multiplayer, highest climber / last one not caught by lava wins.

Look: stylized interior, cool emergency lights, lava glow from the shaft, heat-haze fog rising. Controls: WASD, Space, mouse look. No outdoor villa, no elevator shortcut, no shop, no story. Make the 1F-to-6F stair climb fun first.
```

## 2. 完整 Prompt（生成后发给创作代理）

```
你是 Wanaka 创作代理。请用引擎现有能力（WebGPU 渲染、角色控制器、刚体、运动学物体、触发体积、灯光、简单游戏逻辑、多人同步）做一款可立即试玩的「地板即熔岩」游戏。

场景必须局限在一栋大楼内部：玩家只在楼梯间里往上爬。不要室外岛屿、别墅院子、泳池、开放屋顶公园。相机大部分时间应能看见楼梯、休息平台和井底涌上来的熔岩。

# 游戏名
Stairwell Lava / 楼梯间熔岩

# 一句话
熔岩从一楼涨上来。沿着楼梯往上爬，别被追上。

# 模式
- 第三人称 3D，垂直逃生
- 1 人练习 / 2–8 人同场（用引擎联网）
- 流程：出生在一楼 → 倒计时 → 熔岩上涨 → 沿楼梯爬到天台 / 被追上

# 核心循环（必须可玩）
1. 所有玩家出生在一楼大堂楼梯口，给 2 秒熟悉手感。楼梯此时可安全站立。
2. 画面大字倒计时 5-4-3-2-1，然后砸出 FLOOR IS LAVA。
3. 一楼地面变成熔岩触发体：碰到就淘汰。熔岩是填满楼梯井底部的体积，持续沿井向上涨，淹没已经经过的楼梯和平台。
4. 玩家只能站在：楼梯踏步、休息平台、还没被淹没的栏杆平台、断裂台阶的剩余部分、可推纸箱顶面。
5. 熔岩上涨速度让认真爬的人刚好能逃：大约 40–60 秒从 1 楼涨到 6 楼。太慢会无聊，太快会不公平。
6. 单人：3 条命；触熔岩扣 1 命，在上一层已激活的休息平台检查点重生。碰到楼顶天台安全门 = 通关。
7. 多人：被熔岩碰到即淘汰变旁观。第一个碰到天台安全门的人获胜；若无人到达，最后未被追上者获胜。按 R 全体在一楼重生再开。

# 玩家与手感
- 用角色控制器，不要纯刚体人。必须能稳定站在台阶上，不要一步滑下去。
- 台阶高度约 0.18–0.22 米，正常走就能上；跳跃用于缺口、坍塌段和跨层栏杆。
- 二段跳只用于缺口（缺 3–5 级台阶），不要让人一跳跳过整层。
- 土狼时间 0.12s，跳跃缓冲 0.14s。
- 纸箱：动态刚体，可推到缺口当垫脚，掉进熔岩后 3 秒烧毁。
- 相机：过肩第三人称，在狭窄楼梯间碰撞时拉近；优先看见上方楼梯和下方熔岩。

# 关卡（一栋楼，一条上楼路线）
垂直结构，6 层，折返楼梯（switchback）：
- 1F 大堂：出生点、第一段完整楼梯（教学：先安心往上跑）。
- 1.5F / 2F：休息平台检查点。开始出现缺 2–3 级的台阶，必须跳。
- 3F：一段楼梯中间塌了，只剩两侧踏步或一根斜梁，要侧跳。平台上有 2–3 个可推纸箱。
- 4F：若干踏步站上 1.2 秒后开裂掉落。栏杆可站，但很窄。
- 5F：一段楼梯正在往下垮（运动学，缓慢倾斜），必须在塌完前冲过去。
- 6F 天台门：短平台 + 安全门触发体。进门即胜。

楼梯井是中空的，玩家往下看能看到熔岩在涨。每层休息平台外侧用墙和栏杆拦住，防止无意义掉出大楼。不要做第二条主路，不要电梯当捷径（电梯门是关死的布景即可）。

物体行为（用物理，不要假动画）：
- 开裂踏步：站上 1.2 秒后变红、抖动，再 0.4 秒取消碰撞并掉进井里。
- 垮塌梯段：整段楼梯作为运动学物体在 8 秒内向下旋转塌掉。
- 熔岩：楼梯井底部的触发体积 + 自发光表面，沿 Y 轴上涨；热浪雾从井底向上。

# 胜负（写死，不要模糊）
- 接触熔岩触发体 → 淘汰（多人）或扣命（单人）。
- 从楼梯井掉进熔岩 → 同上。
- 单人胜：触碰 6F 天台安全门。
- 多人胜：最先触碰安全门者；否则最后存活者。
- 禁止：枪、血条磨死、室外跑酷、电梯通关。

# 表现
- 风格化室内：混凝土楼梯、金属栏杆、应急灯冷白、出口标志绿光。
- 井底熔岩橙红自发光，把墙和栏杆下沿映红。楼越高，上方越暗、下方越亮红。
- 倒计时和 FLOOR IS LAVA 全屏、有冲击力。
- HUD：当前楼层、熔岩距离（或「熔岩已到 X 层」）、单人剩余生命、多人存活人数。R 重开。
- 音效：倒计时、熔岩沸腾在井底回响、脚步、踏步开裂、金属栏杆、胜利。可先占位。

# 明确不要做
室外场景、别墅、泳池、岛屿、开放世界。
电梯/飞索/传送通关。商店、装备、技能树、NPC、枪。
不要把熔岩做成可站立的地面碰撞体。
不要做多栋楼或多张图。先让这一条 6 层楼梯 40–60 秒内好玩。

# 验收（做完先自测这些）
- 整张图都在楼内，主路径是爬楼梯，不是跳沙发。
- 倒计时结束前一楼可站；结束后踩一楼地面立刻淘汰。
- 能沿楼梯跑上楼，缺口处能跳过去并站稳在台阶上。
- 熔岩沿楼梯井上涨，会淹没下层楼梯，上层仍可站。
- 单人能从 1 楼爬到天台门；多人能分出胜负并重开。
- 狭窄楼梯间里相机不穿墙、不卡死。
```

## 3. 迭代 Prompt（按顺序发给代理，一次一条）

生成能跑之后，用这些短指令修，不要一次全贴：

1. **锁场景**  
   `删掉所有室外物体。地图只能是一栋楼的室内楼梯间：台阶、休息平台、栏杆、井底熔岩。玩家的唯一前进方向是往上爬楼梯。`

2. **手感**  
   `角色要能稳定走上台阶，不要滑下来。缺口用二段跳刚好能过，不能一跳跳过整层。加上 0.12 秒土狼时间和跳跃缓冲。`

3. **熔岩规则**  
   `熔岩必须是 Trigger / 伤害体积，从楼梯井底部沿 Y 轴上涨。绝不能当可行走地面。碰到就淘汰。倒计时结束前一楼是安全的。`

4. **可读性**  
   `应急灯照亮楼梯踏步。熔岩用高亮橙红自发光，从井底映红下层墙壁。当前可走的台阶要能一眼看清。把 FLOOR IS LAVA 做成屏幕中央大标题。`

5. **节奏**  
   `熔岩大约 50 秒从 1 楼涨到 6 楼。1–2 层完整楼梯当教学，3 层开始缺口，4 层开裂踏步，5 层垮塌梯段，6 层冲刺进天台门。`

6. **楼梯机关**  
   `每层只加一种麻烦：缺步、开裂、垮塌、或两个纸箱。不要把一层堆满。开裂踏步站 1.2 秒后掉落。`

7. **单人关**  
   `单人三命。每层休息平台设检查点。碰到平台就更新重生点。6F 天台安全门出通关 UI。`

8. **多人**  
   `2–8 人同一楼梯井往上爬。淘汰后旁观。先到天台门者胜；否则最后存活者胜。按 R 全体回一楼再开。`

若代理把场景做成室外或家具跑酷，用这句拉回来：

```
停。场景只能是大楼室内楼梯间。删掉院子、家具竞技场和室外。唯一玩法是沿楼梯往上爬，躲避从楼下涨上来的熔岩。把这条楼梯的手感和熔岩触发修好。
```

## 4. 可选皮肤：北京居民楼楼梯间

若要沿用本仓库的剪纸气质，把短 Prompt 里的美术段换成：

```
美术改成剪纸风北京老居民楼：灰绿水磨石踏步、绿漆铁栏杆、每层休息平台的小窗户、墙上的楼层号和「禁止堆放」标语。玩家是一只系红围巾的熊猫。检查点是平台上的红灯笼。6F 天台门换成露天晾衣杆旁的铁门。规则不变：只在楼梯间里往上爬，熔岩从一楼往上追。
```

## 5. 怎么用

1. 打开 [studio.wanaka.fun](https://studio.wanaka.fun/) → Create。
2. 粘贴 **短 Prompt**，等它搭出室内楼梯和角色控制器。
3. 进 Play 测一次：是不是在楼里爬楼梯，一楼变熔岩后会不会死。
4. 把 **完整 Prompt** 发给创作代理，再按 **迭代 Prompt** 一条条改。
5. 手感对了再点 Publish。
