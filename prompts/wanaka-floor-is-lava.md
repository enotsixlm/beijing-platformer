# Wanaka 引擎 · Floor is Lava 创作 Prompt

把下面的 **短 Prompt** 贴进 [Wanaka Studio](https://studio.wanaka.fun/) 的 Create 输入框，生成可玩草稿。  
生成后把 **完整 Prompt** 发给创作代理，用来补齐规则、物理和回合循环。再按 **迭代 Prompt** 一条条打磨。

Wanaka 引擎擅长：WebGPU 光照、刚体物理、角色控制器、移动平台、触发体积、多人联网。这份 prompt 只调用这些能力，不堆商店、背包或开放世界。

---

## 1. 短 Prompt（先贴这一段）

```
做一个第三人称 3D「地板即熔岩」派对生存游戏，1–8 人，浏览器可玩。

场景：黄昏火山岛上的一座崩塌度假别墅，院子、泳池、家具、阳台和屋顶都漂在岩浆上方。开局 5 秒倒计时，地面变成发光熔岩（触发即死，不可站立）。玩家用角色控制器跑跳（含二段跳、土狼时间），踩家具、石台、摇晃木板和可推动的木箱求生。部分地砖站 1.2 秒后开裂掉进熔岩；熔岩每 20 秒上涨一截。最后活着的人获胜；单人模式坚持到屋顶灯塔或存活 3 分钟。

画面：风格化高对比，熔岩自发光 + 热浪雾 + 金色晚霞。操作：WASD 移动，空格跳跃，鼠标转视角。先做出一个 60 秒就很好玩的单场景循环，不要商店、剧情或多余系统。
```

English (if the agent responds better in English):

```
Build a third-person 3D Floor-is-Lava party survival game for 1–8 players, playable in the browser on the Wanaka engine.

Setting: a crumbling volcanic-island villa at golden hour — courtyard, pool, furniture, balconies, and rooftops floating above magma. After a 5-second countdown, the ground becomes emissive lava: a kill trigger, not a walkable collider. Players use a character controller (run, jump, double jump, coyote time) and survive by standing on furniture, stone ledges, tilting planks, and pushable crates. Tiles crack and fall after 1.2s of standing. Lava rises every 20 seconds. Last player standing wins; solo mode: reach the rooftop beacon or survive 3 minutes.

Look: stylized, high contrast, glowing lava, heat-haze fog, warm rim light. Controls: WASD, Space to jump, mouse look. Ship one fun 60-second arena loop. No shop, inventory, or story.
```

## 2. 完整 Prompt（生成后发给创作代理）

```
你是 Wanaka 创作代理。请用引擎现有能力（WebGPU 渲染、角色控制器、刚体、运动学移动平台、触发体积、灯光、简单游戏逻辑、多人同步）做一款可立即试玩的「地板即熔岩」游戏。一次只做一个圆形竞技场，先保证手感，再谈花样。

# 游戏名
Lava Last Stand / 熔岩终局

# 一句话
倒计时结束，地板变成熔岩。跳上还能站的东西，活到最后。

# 模式
- 第三人称 3D，派对生存
- 1 人练习 / 2–8 人同场（用引擎联网）
- 回合制：准备 → 倒计时 → 熔岩阶段 → 结算 → 下一回合

# 核心循环（必须可玩）
1. 所有玩家出生在别墅中庭的安全地面上，给 2 秒熟悉手感。
2. 画面大字倒计时 5-4-3-2-1，然后砸出 FLOOR IS LAVA。
3. 地面（院子、室内地板、草地、泳池水面）全部换成熔岩触发体：碰到就淘汰，立刻播放坠落/烧灼，角色变成观战相机。
4. 只有标记为 Safe 的物体可站：沙发、餐桌、雕像底座、阳台、石柱顶、悬挂木板、缓慢平移的石筏、可推木箱顶面。
5. 熔岩每 20 秒上涨约 1.5 米，淹没最矮的安全点，逼玩家往上爬。
6. 场上只剩 1 人，或到达回合时限 90 秒：显示胜者、存活时间、淘汰顺序。按 R 或按钮再来一局。
7. 单人：3 条命，触熔岩扣 1 命并在最近安全检查点重生；登上屋顶灯塔 = 通关。没命则失败。

# 玩家与手感
- 用角色控制器，不要纯刚体人，避免站不稳、滑下平台。
- 移动速度适中，跳跃高度能上约 1.6–2.0 米的台子，二段跳可再补一小段。
- 土狼时间 0.12s，跳跃缓冲 0.14s，落地可被移动平台载走。
- 推箱：木箱是动态刚体，质量适中，可推到熔岩上当临时踏脚石，在熔岩里会着火并在 4 秒后沉没。
- 相机：过肩第三人称，碰撞时拉近，不要穿墙。

# 关卡（一座岛，一张图）
中庭出生点 → 客厅家具区（矮、教学）→ 泳池石筏（平移平台）→ 倾斜的断裂楼梯 → 二楼阳台（开裂地砖）→ 外墙脚手架 → 屋顶灯塔（终点/决赛高台）。

安全物约 25–40 个，高低错落，跳跃间距要「紧张但公平」。外围用不可见墙，防止掉出世界。

物体行为（用物理，不要假动画）：
- 开裂砖：站上 1.2 秒后变红、抖动，再 0.4 秒取消碰撞并作为刚体掉进熔岩。
- 跷跷木板：有铰链/软约束，人站一端会翘。
- 石筏：运动学平台，沿泳池来回，玩家站上去必须被带着走。
- 弹簧垫：落地给向上冲量，接到阳台。
- 熔岩：大面积触发体积 + 自发光网格 + 缓慢噪声起伏；热浪雾从熔岩向上。

# 胜负（写死，不要模糊）
- 接触熔岩触发体 → 淘汰（多人）或扣命（单人）。
- 掉出地图边界 → 同熔岩。
- 多人胜：最后未淘汰者。平局：比存活时间。
- 单人胜：触碰屋顶灯塔触发体。
- 禁止：掉血条磨死、毒圈、枪战。这不是射击游戏。

# 表现
- 风格化，不是写实扫描件。熔岩橙红自发光，天空火山晚霞，强边缘光。
- 倒计时和 FLOOR IS LAVA 要全屏、有冲击力。
- 淘汰：短火花 + 熔岩飞溅，不要长过场。
- HUD：倒计时、回合时钟、存活人数、单人剩余生命。R 重开。
- 音效：倒计时滴答、熔岩沸腾底噪、跳跃、开裂、淘汰、胜利号角。可先占位。

# 明确不要做
商店、装备、技能树、任务 NPC、开放世界、载具驾驶、枪、复杂 UI。
不要把熔岩做成可站立的地面碰撞体。
不要第一版就做十张图。先让这一张图 60 秒内好玩。

# 验收（做完先自测这些）
- 倒计时结束前地面安全，结束后踩地面立刻淘汰。
- 能跳上沙发/箱子并站稳，移动平台会载人。
- 开裂砖会掉，不会卡住玩家。
- 熔岩上涨后矮平台被淹没，高平台仍可站。
- 单人能从出生点一路跳到灯塔；多人能分出胜负并重开。
- 60fps 量级，场景物体数量克制。
```

## 3. 迭代 Prompt（按顺序发给代理，一次一条）

生成能跑之后，用这些短指令修，不要一次全贴：

1. **手感**  
   `跳跃再高一点，落地更跟手。加上 0.12 秒土狼时间和跳跃缓冲。站在移动石筏上必须被带着走，不要滑下去。`

2. **熔岩规则**  
   `熔岩必须是 Trigger / 伤害体积，绝不能当可行走地面。碰到就淘汰。倒计时结束前院子是安全的。`

3. **可读性**  
   `安全平台用冷色石头/木色，熔岩用高亮橙红自发光。开裂前平台变红闪两下。把 FLOOR IS LAVA 做成屏幕中央大标题。`

4. **节奏**  
   `熔岩改为每 15 秒涨一次，每次涨 1.2 米。前 20 秒只灭地面，让新手先学会跳家具。`

5. **物理玩具**  
   `加 6 个可推木箱。箱子推进熔岩能当踏板，但 4 秒后烧毁下沉。加一块跷跷板。`

6. **单人关**  
   `单人三命，每个高度层设检查点灯笼。碰到灯笼重生点更新。屋顶灯塔出通关 UI。`

7. **多人**  
   `2–8 人同场，淘汰后变旁观。显示淘汰顺序。最后一人胜利。按 R 全体重生再开一局。`

8. **Juice**  
   `补跳跃尘土、熔岩飞溅、开裂震动、胜利慢动作 0.8 秒。倒计时用语音滴答。`

若代理跑偏，用这句拉回来：

```
停。不要加新系统。回到「倒计时 → 地面变熔岩 → 跳上安全物 → 熔岩上涨 → 分出胜负」这一条循环，把跳跃手感和熔岩触发修好。
```

若要沿用本仓库的熊猫跑酷气质，把短 Prompt 里的场景段换成：

```
美术改成剪纸风北京：天安门广场的地砖变成熔岩，玩家是一只系红围巾的熊猫。安全落脚点是石狮、华表基座、灯笼、牌楼横梁、胡同屋顶和会左右移动的人力车顶。路线仍是一张中型广场+胡同屋顶，终点是城楼灯塔。保持地板即熔岩规则不变。
```

## 5. 怎么用

1. 打开 [studio.wanaka.fun](https://studio.wanaka.fun/) → Create。
2. 粘贴 **短 Prompt**，等它搭出场景和角色控制器。
3. 进 Play 测一次：地面会不会杀你、能不能跳上家具。
4. 把 **完整 Prompt** 发给创作代理，再按 **迭代 Prompt** 一条条改。
5. 手感对了再点 Publish。
