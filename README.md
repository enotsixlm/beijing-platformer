# 楼梯即熔岩

第三人称 3D「地板即熔岩」：整张图都在一栋室内大楼的楼梯间。从一楼大堂出生，沿折返楼梯往上爬，逃离从楼下涌上来的熔岩。浏览器可玩，1–8 人（本机一名玩家 + CPU 逃者）。

![title](shots/0-title.png)

## 玩法

- 6 层楼，每层休息平台 + 折返楼梯
- 开局 5 秒倒计时后，一楼地面变成发光熔岩（站上去即死）
- 熔岩沿楼梯井持续上涨
- 跑跳含二段跳与土狼时间
- 部分踏步站 1.2 秒后开裂掉落；有的梯段缺级，必须跳过
- 少量可推纸箱
- 先到楼顶天台安全门获胜；多人看谁爬得最高、谁最后被追上

## 操作

WASD 移动 · 空格跳跃 · 鼠标转视角 · R 重开

## 本地运行

```bash
npm install
npm run dev
```

冒烟测试：`npm run smoke`
